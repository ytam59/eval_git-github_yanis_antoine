Bienvenue sur notre projet !

Nous sommes Yanis et Antoine. Dans le cadre de notre travail de groupe, nous découvrons et utilisons Git et GitHub pour apprendre à travailler ensemble sur un projet informatique.

Découvrir le projet

Présentation du projet

Notre objectif est de réaliser un travail en groupe en utilisant Git et GitHub.

Git est un outil qui permet de suivre les modifications d'un projet et de retrouver ses anciennes versions.

GitHub est une plateforme en ligne qui permet de stocker nos projets et de collaborer avec d'autres personnes.

Les étapes de notre travail

1. Création du projet

Création des fichiers HTML et CSS pour construire notre site web.

2. Utilisation de Git

Utilisation des commandes Git pour enregistrer les modifications de notre travail.

3. Utilisation de GitHub

Mise en ligne du projet sur GitHub pour partager notre code.

4. Travail en équipe

Collaboration entre Yanis et Antoine, partage des modifications et amélioration du site.

Notre objectif

Apprendre à travailler à plusieurs sur un même projet, comprendre le fonctionnement de Git et GitHub et améliorer nos compétences en développement web.
